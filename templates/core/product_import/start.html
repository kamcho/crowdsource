How to prepare your import

More accurate supplier details usually mean less editing later.

  1. Open the supplier’s public product listing. Copy the product title, description, specifications, packaging details, minimum order quantity (MOQ), and available options.
  2. Include the variation and price table. Copy rows for sizes, colors, SKUs, and per-unit prices if the supplier provides them. If a detail is missing, leave it out rather than guessing.
  3. Add supplier details when available. Include the supplier company or store name and a public supplier/store link in the pasted text if you want to use the supplier step.
  4. Paste a public product URL (optional). The importer may try to fetch listing images later. Some supplier sites block automated image fetching, so you can upload images in the product wizard instead.
  5. Parse, then review every step. AI prepares a draft; it does not publish immediately. Check the product details, category, supplier, variations, and images, then publish only when everything is correct.
Useful details to copy

Product name · material/specifications · package size or weight · MOQ · color/size options · SKU · unit price · supplier name

Use information from a public listing. Do not paste account passwords, payment details, or other private information.
